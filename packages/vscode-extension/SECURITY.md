# Security

Please use GitHub private vulnerability reporting for `Haiyang-Bian/vscode-agent-bridge`. Do not publish live tokens, descriptors, IPC endpoints or an unredacted Codex configuration.

Version `0.6.1` adds cancellation-safe workspace onboarding and explicit bridge readiness to the bounded ordinary-experiment reflection and memory-only Agent activity visibility introduced in `0.6.0`. It retains guarded IDE save/format/pure-text Code Actions and read-only terminal observation, and exposes no generic file opening, terminal input, shell execution or Agent-callable Git operation. See the repository [security policy](https://github.com/Haiyang-Bian/vscode-agent-bridge/blob/master/SECURITY.md) for the exact policy, privacy and recovery boundaries.
