# VS Code Agent Bridge 0.9.0

Status: unpublished Windows x64 side-load candidate. Marketplace publishing remains disabled.

## Scope

`0.9.0` upgrades the authenticated bridge to protocol v8 and exactly 53 tools. It adds read-only extension reflection, configuration-schema discovery, coverage-aware IDE output-source discovery, a bounded Problems event timeline and captured Debug Console output. The Bridge does not activate inspected extensions, call their exports or execute contributed commands.

Output access is deliberately honest about coverage. The Bridge can read only already opened Output documents or streams it captured through existing Terminal, Task and Debug integrations. It never switches an Output Channel, reads private VS Code logs or claims access to pre-activation output. Current Profile name and ID remain `null` because stable VS Code APIs do not expose them.

Install directly over `0.8.0`, rerun **Configure Codex**, restart Codex and use Overview plus the nine new read tools to inspect installed capabilities and IDE signals.
