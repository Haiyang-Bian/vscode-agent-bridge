# VS Code Agent Bridge 0.10.0

Status: unpublished Windows x64 side-load candidate. Marketplace publishing remains disabled.

## Scope

`0.10.0` upgrades the authenticated bridge to protocol v9 and exactly 58 tools. It adds fixed-endpoint Marketplace discovery, exact two-phase native installation and manifest-declared configuration for the current VS Code Profile. Publisher Trust remains owned by VS Code; the Bridge never accepts a URL or VSIX path, invokes an install CLI, downgrades, uninstalls, silently updates or executes an arbitrary command.

Global Profile updates use a guarded local undo journal and are explicitly outside experiment restoration. Workspace and WorkspaceFolder updates remain experiment checkpoints. Sensitive and undeclared settings are unavailable through MCP, and private Profile identity/storage remains unread.
