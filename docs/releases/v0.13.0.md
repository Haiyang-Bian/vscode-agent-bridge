# v0.13.0 candidate validation

Phase 1 implements the per-user shared HTTP daemon from [ADR 0022](../adr/0022-per-user-http-daemon.md), retaining RPC v11 and 64 tools. It does not publish Marketplace artifacts, create a release tag or implement extension active registration.

Required gates are the impact-selected complete check, two full isolated Extension Host runs and the artifact gate. Artifact acceptance uses the compiled hidden-console EXE, actual isolated login-task installation/rollback, real window reload and installed-VSIX HTTP calls. See [Windows acceptance](../acceptance/v0.13.0-windows-x64.md) and [installation/recovery](../installation.md).

Version files, checksums and candidate bundles are local build outputs. Record actual verification in a new dated audit; this checklist alone is not evidence of execution. Cross-machine and second-Windows-identity ACL validation remain separate from local acceptance.
