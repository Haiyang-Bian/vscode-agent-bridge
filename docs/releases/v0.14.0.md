# v0.14.0 candidate validation

Status: unpublished Windows x64 side-load candidate. Marketplace publishing and a formal release tag remain out of scope.

Version 0.14.0 implements the direct IDE Bridge decision in [ADR 0023](../adr/0023-direct-ide-bridge.md). It upgrades extension RPC to v12, removes experiment and Managed Worktree product surfaces, and exposes exactly 57 catalog-derived tools. Trust, local-root containment, stale-state hashes/versions, prepared handles, Task/Debug fingerprints and client-owned approval annotations remain enforced.

The Activity Bar now contains only Status and Agent Activity. Agent operations preserve editor focus; legacy experiment storage is notice-only and is never loaded or deleted automatically. Protocol compatibility and release alignment are reported independently.

Required gates are the complete fast check, two full isolated Extension Host runs and the artifact gate. Artifact acceptance uses the compiled hidden-console EXE, correlated capacity errors, actual isolated login-task upgrade/rollback, bounded version retention and installed-VSIX HTTP calls. See [Windows acceptance](../acceptance/v0.14.0-windows-x64.md) and [installation/recovery](../installation.md).

Build outputs and hashes are local evidence until recorded in a new dated audit. Cross-machine and second-Windows-identity ACL validation remain separate from same-user local acceptance.
