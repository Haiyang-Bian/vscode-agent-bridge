# VS Code Agent Bridge 0.12.0

Status: locally verified, unpublished Windows x64 side-load candidate. Marketplace publishing remains disabled; cross-user/cross-machine acceptance is still required.

## Scope

`0.12.0` upgrades the authenticated bridge to protocol v11 and exactly 64 catalog-derived tools. It permits Agent-authored Shell/Process Tasks and Debug adapter configurations only through observable VS Code APIs, complete fingerprints, active experiments, root/session binding, open-world annotations, Activity correlation and final checkpoints. Definitions are temporary by default; persistence to `tasks.json` or `launch.json` is a separate exact-hash/provenance operation.

The release also adds canonical path/reparse protection, exact expiring provider document grants, hash-only extension-setting reads, a recoverable Global Profile journal, Windows SID/ACL descriptor hardening, version-tolerant instance discovery, restored initializing/degraded publication, bounded Usage Insight rotation/flush, actionable default Output inventory and typed catalog-complete MCP registration.
