# VS Code Agent Bridge 0.5.1

Status: unpublished Windows x64 side-load patch candidate. Marketplace publishing remains disabled.

## Patch scope

`0.5.1` keeps protocol v4 and the 21-tool surface from `0.5.0` while correcting two acceptance findings:

- `vscode_format_document` now treats a formatter response with no edits as a successful no-op (`applied: false`, `editCount: 0`) instead of reporting `FORMAT_PROVIDER_UNAVAILABLE`.
- A machine-scoped, default-off `vscodeAgentBridge.enableAcceptanceFixtures` setting registers one deterministic pure-text Quick Fix for positive Code Action acceptance testing.

The acceptance fixture only targets an existing `*.bridgeaction` document containing `BROKEN_E2E`, returns a command-free and resource-operation-free `WorkspaceEdit`, and replaces the marker with `FIXED_E2E`. Normal installations are unchanged because the setting defaults to `false`. Applying the action still requires a trusted local workspace, an active experiment, explicit instance/session routing, and fresh version/hash preconditions.
