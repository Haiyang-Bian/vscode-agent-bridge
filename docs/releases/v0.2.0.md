# VS Code Agent Bridge 0.2.0

First public Windows x64 release.

## Highlights

- Self-contained platform VSIX with a Bun-compiled baseline x64 MCP executable.
- One confirmed VS Code command configures Codex without requiring Bun, Node.js or source code.
- Eight local read-only IDE tools covering window discovery, editor context, unsaved buffers, diagnostics, symbols, definitions, references and hover.
- Authenticated local IPC, live descriptor probing, atomic descriptor/config writes, bounded outputs and stable error codes.
- Real VS Code Extension Host tests plus EXE/VSIX content and MCP STDIO smoke tests.

## Supported platform

- Windows x64
- VS Code 1.95.0 or newer desktop UI extension host
- Local workspaces, including read-only queries in untrusted workspaces

Remote SSH, WSL, Dev Containers, Codespaces, Linux, macOS, Windows ARM64, Open VSX and write operations are not included.
