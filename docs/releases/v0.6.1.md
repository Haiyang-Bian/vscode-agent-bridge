# VS Code Agent Bridge 0.6.1

Status: unpublished Windows x64 side-load patch candidate. Marketplace publishing remains disabled.

## Scope

`0.6.1` keeps protocol v5 and the 26-tool IDE surface from `0.6.0`. It fixes the two lifecycle findings from the [v0.6.0 self-bootstrap reload audit](../audits/2026-08-10-v0.6.0-self-bootstrap-reload.md): interactive mutations can no longer outlive a cancelled caller, and the bridge is discoverable with an explicit lifecycle while experiment storage recovers.

The patch also prevents Git-ignored build output from expanding future experiment checkpoints and validates duplicate content-addressed Blobs only once during recovery. Existing experiment data, old MCP executables and the `0.6.0` audit evidence are preserved. Install directly over `0.5.1` or `0.6.0`, then rerun **Configure Codex** and restart Codex.
