# VS Code Agent Bridge 0.11.0

Status: unpublished Windows x64 side-load candidate. Marketplace publishing remains disabled.

## Scope

`0.11.0` upgrades the authenticated bridge to protocol v10 and exactly 60 tools. It adds a static reviewed extension adapter catalog and the first production integration, `python.environment`, implemented through Microsoft's pinned `@vscode/python-extension` facade for `ms-python.python`.

Catalog listing never activates an extension. An explicit integration-state request may activate only the fixed reviewed extension and returns only active interpreter path, environment type/name, Python version and bitness. Missing extensions return an explicit unavailable state; incompatible versions, activation failures and API drift fail closed. Arbitrary extension IDs, commands, exports, arguments and actions remain unavailable.
