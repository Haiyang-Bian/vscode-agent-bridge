# VS Code Agent Bridge 0.8.0

Status: unpublished Windows x64 side-load candidate. Marketplace publishing remains disabled.

## Scope

`0.8.0` upgrades the authenticated bridge to protocol v7 and exactly 44 tools. It introduces the native VS Code Agent Bridge Hub, an authoritative capability catalog and privacy-preserving local usage insights. It adds no new workspace mutation and retains every v0.7 trust, experiment, Task, Debug, terminal and recovery boundary.

The Hub uses native Tree Views and keeps the previous Activity Bar container ID so upgrades preserve placement. Local insight events are append-only per MCP process, retained for 30 days with a 20 MiB total cap and never uploaded. They exclude parameters, results, paths, source, hashes, terminal content, debug values, environment variables and credentials.

Install directly over `0.7.0`, rerun **Configure Codex**, restart Codex and use Overview/Capabilities/Usage Insights to inspect the bridge.
