# VS Code Agent Bridge 0.7.0

Status: unpublished Windows x64 side-load candidate. Marketplace publishing remains disabled.

## Scope

`0.7.0` upgrades the authenticated bridge to protocol v6 and exposes exactly 42 bounded IDE workflow tools. It adds guarded JSONC and text-resource changes, fingerprinted VS Code Tasks, and named static Debug workflows with a fixed DAP whitelist. The extension still exposes no arbitrary shell, terminal input, generic VS Code command, unrestricted filesystem, arbitrary Task/DAP request or Agent-callable Git operation.

The machine policy is now one master switch plus `explicit`/`aggressive` execution mode. Existing users who explicitly selected a restrictive v0.6 policy must make a new enable/disable choice before the bridge is published. **Configure Codex** no longer chooses an approval mode; Codex, user policy or a supervising Agent decides from the tools' declared side effects.

New experiments use resource-history schema v2. Legacy sessions remain readable and are not migrated or deleted; active v1 sessions cannot perform resource changes. Restore reconstructs captured workspace text and resource structure on disk, but Task/Debug effects outside the workspace, external services, network state, environment variables, databases, Git history and processes are not recoverable.

Install directly over `0.6.1`, run **Configure Bridge**, rerun **Configure Codex**, and restart Codex. Old MCP executables and experiment data remain in place.
