# VS Code Agent Bridge 0.8.0 Windows x64 acceptance

Run this procedure on a different Windows x64 computer with a clean VS Code profile, no Bun or Node.js, and no clone of this repository. Install the checksum-verified VSIX directly over `0.7.0`; do not uninstall first.

## Upgrade and Hub

1. Confirm extension ID `AliceLin.vscode-agent-bridge`, version `0.8.0`, protocol v7 and exactly 44 tools after rerunning **Configure Codex** and restarting Codex.
2. Confirm the existing Activity Bar location is preserved but its title is **VS Code Agent Bridge**.
3. Confirm Overview, Experiments, Agent Activity, Capabilities and Usage Insights are native Tree Views. Overview must show version/protocol, bridge publication, Codex configuration state, trust, active experiment, Problems count and Task/Debug/Terminal counts without tokens, IPC endpoints, source, commands, output or absolute paths.
4. Expand every Capabilities category and compare it with `vscode_get_bridge_capabilities`. The 44 names, annotations, intent, side effects, experiment requirement, recoverability, open-world and sensitivity fields must match.

## Privacy-preserving usage insights

1. Clear local insights, perform at least one read, prepare, apply, save, Task/test and explicit checkpoint workflow, then call `vscode_get_usage_insights`.
2. Confirm category/tool counts, outcome ratios, friction and workflow closure update. Trigger at least three safe stale-precondition rejections and confirm the deterministic stale-state suggestion cites the count.
3. Export the aggregate report and scan the local insight directory/report for the unique source marker used in the test, workspace path, username, terminal output, Task command, debug expression/value, environment variable, token and document hash. None may appear.
4. Start two Codex clients concurrently and confirm each creates an independent append-only insight session without malformed events or lock contention.
5. Clear insights again and confirm Usage Insights returns an empty 30-day window while experiments and Agent Activity remain intact.

## v0.7 regression

1. Recheck unsaved document reads, diagnostics, symbols, definitions, references, hover, formatting no-op, pure-text Code Action and visible multi-file writes.
2. Recheck JSONC/resource updates, Task execution/output/termination, named Debug state/control/breakpoints/evaluate/setVariable, resource restore and the master switch.
3. Run the Managed Worktree advanced smoke test and confirm ten private commits still promote as one target commit.
4. Confirm no generic command, arbitrary DAP request, terminal input, shell, unrestricted filesystem, extension install or Agent-callable Git tool exists.

## Report

Produce privacy-scrubbed Markdown and JSON reports containing Windows, VS Code, extension/protocol versions, artifact SHA-256 values, each result, coverage limitations and `overallStatus`. Replace machine roots with placeholders and exclude all content prohibited above.

Only `overallStatus: passed` marks `0.8.0` as Windows x64 cross-machine verified. A failure keeps this candidate immutable and should produce a patch release.
