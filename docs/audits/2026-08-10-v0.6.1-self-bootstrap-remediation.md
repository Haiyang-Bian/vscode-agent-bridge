## Scope and method

This follow-up evaluates the code changes made in response to `AUDIT-2026-08-10-01` and `AUDIT-2026-08-10-02`. It uses deterministic E2E-only delays to hold experiment initialization for 10 seconds and onboarding for 11 seconds, both longer than the old inner lifecycle boundaries. It also creates a Git-ignored build-output file during an active experiment and observes the checkpoint timeline.

A read-only aggregate inspection of the existing audited checkpoint found 1,518 documents: 1,444 were Git-ignored, 61 were tracked, and the remainder were other bounded states. This establishes ignored-output capture as a material amplifier of the approximately 61 MB legacy journal; no source, absolute path or Blob content was read into this report.

## Findings and closure state

### AUDIT-2026-08-10-01: automated closure passed

Cancellation now crosses MCP, local RPC and handler layers. Interactive writes have a 90-second inner timeout, but timeout extension is not the safety mechanism: disconnecting or cancelling aborts the extension handler, which checks the signal before settings or experiment persistence. The regression keeps the prompt path open beyond both old inner limits and observes zero settings changes after cancellation.

### AUDIT-2026-08-10-02: implementation closure passed; installed-journal validation remains

The bridge registers before recovery and reports explicit lifecycle. The deterministic delayed-recovery test proves discovery and `initializing → ready` behavior independent of the operation delay. Recovery also avoids repeated validation of identical Blobs.

The original report's strongest real-world condition—the existing approximately 61 MB partial journal—has not yet been reloaded with an installed `0.6.1` artifact. Therefore this follow-up remains `completed_with_findings` rather than claiming full installed self-bootstrap closure.

### Additional finding: ignored build output amplified experiment storage

- Severity: Medium
- Status: Fixed for future events

The broad watcher had captured Git-ignored build output. Git-backed sessions now retain watcher events only for Git-dirty paths or open documents, with conservative fallback if Git status cannot be obtained. Existing events and Blobs are deliberately preserved; cleanup remains a separate user-controlled lifecycle operation.
