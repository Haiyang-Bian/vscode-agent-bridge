# v0.12.0 security and autonomy release audit

- Date: 2026-08-11
- Status: `completed_with_findings`
- Scope: protocol v11, 64 tools, IDE-mediated autonomous Task/Debug execution, canonical path and language authorization, local identity/ACL hardening, lifecycle/runtime bounds and Windows x64 release gates
- Environment: Windows x64; Bun 1.3.11; isolated VS Code 1.132.0 Extension Host

## Method and preconditions

The audit followed the repository impact planner. It used protocol and deterministic module tests, all-workspace type checks/builds, real MCP STDIO discovery, two consecutive full isolated Extension Host E2E runs, Windows x64 executable self-test, VSIX content and sensitive-data audit, a packaged VSIX Extension Host run and SHA-256 verification. The E2E harness used disposable trusted TypeScript workspaces, Profiles, registry directories, experiments and managed worktrees.

The automated host ran under the current Windows identity. The separate restricted-user ACL and unauthenticated-pipe procedure in [`docs/acceptance/v0.12.0-windows-x64.md`](../acceptance/v0.12.0-windows-x64.md) was not executed locally.

## Findings

1. Severity: informational, open release boundary. The current-user ACL implementation and command construction are verified, but the descriptor has not yet been probed from a second restricted Windows identity. The candidate must remain unpublished until that procedure passes.
2. Severity: informational, not a product or harness failure. An earlier Extension Host attempt was interrupted when the user clicked **Reload Window**, which explains the empty/interrupted host state. It is excluded from failure classification; the later final gate completed two uninterrupted consecutive runs, followed by a packaged run.
3. Severity: informational, evidence boundary. Automated E2E verifies the complete Activity correlation data for prepare, execution, terminal/Debug lifecycle and checkpoint. A separate human visual inspection of that chain in Bridge Hub was not performed, so no manual UX claim is made.
4. Severity: informational, intentional scope. The broad `ExperimentManager` decomposition remains deferred; this release adds bounded collaborators and contracts without claiming that refactor is complete.

## Side effects and artifacts

The automated runs created disposable repositories, Extension Host Profiles, registry descriptors, Tasks, Debug sessions, experiments, checkpoints and managed worktrees. Successful final runs removed their temporary directories and exited their child hosts. No project source, user workspace configuration, `.codex` or `.idea` content was removed.

## Closure criteria

Local candidate closure is complete: final check, repeated real Extension Host workflows, packaged install, executable/VSIX/test-bundle audit, checksums and temporary-resource hygiene all pass. Release closure requires the separate restricted-user or cross-machine acceptance procedure, including descriptor/token denial and unauthenticated-pipe rejection.
